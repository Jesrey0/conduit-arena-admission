# Enrollment prompt card

Read the authorization, operator confirmation, runbook, and provisioning JSON. Treat ISO-8601 timestamps as absolute instants (`Z` means UTC), never as calendar dates. Download bootstrap only from exact `bootstrap.url`, verify SHA-256, and use the one-time invite only for the exact `authorization.accessClass`, privileges, and workspaces. The upload intentionally contains no `.py` file. If pending, report the request ID without secrets; bootstrap may keep polling or safely resume from its private mode-`0600` enrollment state. Stop on any URL, hash, absolute-time expiry, grant, workspace, or permission mismatch.
